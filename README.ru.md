# git-sweep-rs

[English](README.en.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [हिन्दी](README.hi.md) · [Français](README.fr.md) · [Русский](README.ru.md)

> ⚠️ **Внимание: сделайте резервную копию репозитория перед использованием**
>
> Пожалуйста, сделайте резервную копию вашего репозитория перед использованием этого инструмента (например, отправьте важные локальные ветки на удалённый репозиторий или создайте резервную копию). Этот инструмент удаляет ветки, и восстановление удалённых веток не тривиально. При первом использовании выполните `git-sweep-rs preview`, чтобы просмотреть ветки, которые будут удалены, и только после проверки запускайте `cleanup` или `cleanup-local`. Для пропуска подтверждений используйте `--force` (с осторожностью).

Инструмент для очистки веток Git, написанный на Rust, помогает быстро удалять ветки, уже слитые в основную ветку (удалённые и локальные).

## ✨ Возможности

- 🚀 Высокая производительность: написан на Rust
- 🔍 Безопасный просмотр: предварительный просмотр веток перед удалением
- 🌐 Очистка удалённых веток: удаляет удалённые ветки, слитые в main
- 💻 Очистка локальных веток: удаляет локальные ветки, слитые в main
- 🎯 Гибкость: настраиваемое имя основной ветки и список исключений
- ✅ Подтверждение: запрашивает подтверждение перед удалением (`--force` для пропуска)

## 📦 Установка

### Homebrew (macOS / Linux)

```bash
brew install leo-yi/tap/git-sweep-rs
```

### Сборка из исходников

Убедитесь, что у вас установлен [Rust](https://www.rust-lang.org/tools/install), затем:

```bash
git clone https://github.com/leo-yi/git-sweep-rs
cd git-sweep-rs
cargo build --release
```

### Установка в систему

**Метод 1: через `cargo install`**

```bash
cargo install --path .
```

**Метод 2: ручная копия**

```bash
sudo cp target/release/git-sweep-rs /usr/local/bin/
```

## 🚀 Использование

### Удалённые ветки

#### Предпросмотр веток для удаления

```bash
git-sweep-rs preview --origin origin --master master
```

#### Удаление удалённых веток

```bash
# запросит подтверждение перед удалением
git-sweep-rs cleanup --origin origin --master master

# принудительное удаление без подтверждения
git-sweep-rs cleanup --force --origin origin --master master
```

### Локальные ветки

#### Предпросмотр локальных веток для удаления

```bash
git-sweep-rs preview-local --master master
```

#### Удаление локальных веток

```bash
# запросит подтверждение перед удалением
git-sweep-rs cleanup-local --master master

# принудительное удаление без подтверждения
git-sweep-rs cleanup-local --force --master master
```

## 📖 Команды

| Команда | Описание | Объект |
|--------:|:--------|:------|
| `preview` | Предпросмотр удалённых веток для удаления | удалённые ветки |
| `cleanup` | Удаление слитых удалённых веток | удалённые ветки |
| `preview-local` | Предпросмотр локальных веток для удаления | локальные ветки |
| `cleanup-local` | Удаление слитых локальных веток | локальные ветки |

### Общие параметры

#### preview / cleanup

- `--origin <ORIGIN>`: имя remote (по умолчанию: `origin`)
- `--master <MASTER>`: имя основной ветки (по умолчанию: `master`)
- `--nofetch`: не получать обновления с удалённого
- `--skip <BRANCHES>`: список веток для пропуска, через запятую
- `--force`: принудительное удаление без подтверждения (только для cleanup)

#### preview-local / cleanup-local

- `--master <MASTER>`: имя основной ветки (по умолчанию: `master`)
- `--skip <BRANCHES>`: список веток для пропуска, через запятую
- `--force`: принудительное удаление без подтверждения (только для cleanup-local)

## 💡 Примеры

### Сценарий 1: Очистка удалённых веток

```bash
# 1. Предпросмотр веток для удаления
git-sweep-rs preview --origin origin --master main

# 2. Подтвердите и удалите
git-sweep-rs cleanup --origin origin --master main
```

### Сценарий 2: Очистка локальных веток

```bash
# 1. Предпросмотр локальных веток для удаления
git-sweep-rs preview-local --master main

# 2. Подтвердите и удалите
git-sweep-rs cleanup-local --master main
```

### Сценарий 3: Пропустить ветки

```bash
# пропустить develop и staging
git-sweep-rs preview --master main --skip "develop,staging"
git-sweep-rs cleanup --master main --skip "develop,staging"
```

### Сценарий 4: Не получать обновления удалённого

```bash
# использовать локально кэшированные данные
git-sweep-rs preview --nofetch
git-sweep-rs cleanup --nofetch
```

## ⚠️ Замечания

1. Удаление удалённых веток — это разрушительная операция
   - Используйте `preview` для проверки
   - Удалённые ветки не всегда просто восстановить
   - Коллегам нужно выполнить `git fetch --prune` для синхронизации

2. Удаление локальных веток
   - Для безопасного удаления используйте `git branch -d`
   - Для принудительного удаления используйте `git branch -D`

3. Имя основной ветки
   - Во многих проектах используется `main` вместо `master`
   - Используйте `--master main`, если нужно

## 🔧 Как это работает

### Очистка удалённых веток

1. Получает обновления с удалённого (если не `--nofetch`)
2. Список удалённых веток через `git for-each-ref`
3. Использует `git cherry` для проверки слияния с main
4. Список слияний
5. Удаляет ветку: `git push origin :branch`

### Очистка локальных веток

1. Список локальных веток, которые были слиты, через `git branch --merged`
2. Исключает основную ветку и список пропусков
3. Список слияний
4. Удаляет локальную ветку через `git branch -d`
